SERI Calculator

The Spatial Effective Rainfall Index — a per-event measure of how ecologically effective a rainfall event is in hyper-arid drylands. It scores not the scalar intensity of a storm but its spatial coherence.

SERI = P · Aα · f(season) · g(substrate)

Inputs

0.68

α = 0.68 is the working value of the concept paper (calibration of α across ≈150 events is reported in the companion paper, Selkh, in prep.). For the Abadla inputs, the perennial-response tier corresponds to α ∈ [0.66, 0.78].

Regional calibration. The seasonal (f) and substrate (g) coefficients and the six tier thresholds are calibrated for the northern Algerian Sahara transect (2013–2024). The framework transfers worldwide, but the numerical values require regional recalibration against locally observed ecological response — the pipeline is released as open code precisely so this reduces to substituting a regional event archive (paper §6.2). This calculator evaluates the index from values you provide; it does not retrieve satellite data.
